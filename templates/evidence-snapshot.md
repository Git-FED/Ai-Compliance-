# Evidence snapshot — draft template

> Store only authorized, minimal, non-sensitive public evidence references. Do not commit screenshots or raw evidence containing personal data, credentials, account identifiers, order data, or tokens. Use fictional data only for self-tests.

- Evidence reference: `[E-##; non-identifying]`
- Fixture label, if fictional: `[FICTIONAL — TEST DATA / NOT FICTIONAL]`
- Source title/publisher: `[TITLE]`
- Public URL (remove query strings, fragments with tokens, and private paths): `[URL]`
- Region/locale and applicable product surface: `[REGION / UNKNOWN]`
- Effective/publication date shown by source: `[DATE / NOT SHOWN]`
- Accessed date/time and time zone: `[DATE / TIME ZONE]`
- What was directly observed (short factual excerpt/paraphrase): `[OBSERVATION]`
- Source type: `[OFFICIAL LAW/REGULATOR / OFFICIAL PLATFORM / PUBLIC STORE PAGE / REVIEWER NOTE / OTHER]`
- Fact status: `[OBSERVED / REPORTED / INFERRED / NOT VERIFIED]`
- Relevant checklist item(s): `[A1…D6]`
- Limitations or conflicts: `[LIMITATIONS]`
- Secure external storage reference, if necessary and approved: `[NON-SENSITIVE POINTER ONLY]`

Before saving: redact identifiers; remove tracking parameters; confirm the material is authorized to retain; verify no personal data, secrets, tokens, payment data, logs, or private account contents are included.
